# 文本采集输出（1.0.3）

文本输出位于插件的 `output` 目录，沿用原 DMM 的分类：

- `localization.json`：界面词典中缺少的键及传入文字。
- `generic_orig.json`：未命中的完整文本。
- `generic.json`：带 `[__split__]` 前缀的缺失片段。
- `generic.fmt.json`：包含 `{0}` 等占位符的格式文本。
- 切换分组后，通用文本使用 `_1` 等后缀；界面词典不分组。

按原版 `Local.cpp` 的 `ordered_json::dump(4, ' ', false)` 输出四空格缩进、UTF-8 无 BOM、可读 Unicode（含 emoji）。引号、反斜杠、换行及其他控制字符仍按 JSON 规范转义。停止创建或追加非原版的 `observed.jsonl`。

保留已有译文、已知文本过滤、去重和临时文件替换机制。已有转义 JSON 仍可正常读取；文件有新增内容时按新格式写出。不会将传入的中文猜测还原为日文，也不会把历史观察日志中的已译文本全量灌入缺失词典。

离线专项覆盖实际记录、分类和写出逻辑，以及全部控制字符与 Unicode 的 JSON 往返、已有译文保留、切组、停用写出、不再生成观察日志。实机采集入口仍需由用户手动运行游戏验证。
